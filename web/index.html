Inside the clean room · what really happened to this file

“We moved banks. Please pay the new account.”

Emails like that cost US businesses $3.05 billion in 2025 (FBI IC3). The person who can stop it is the clerk who opens the invoice. Today she opens it on her own computer and hopes.

Sealed

The file is opened in a fresh room on Vultr: gVisor, no network, no secrets, read-only, 512 MB, 30 seconds. Then the room is destroyed.

Anything that tries, leaves a mark

The room measures the file. An agent on Vultr Serverless Inference writes the code that reads it, and rewrites it if it fails. What the file tried is on the receipt.

Only text comes out

Every field is checked against the file's own text. A new bank, a new pay method, a look-alike sender or a file that tried something holds the payment.
